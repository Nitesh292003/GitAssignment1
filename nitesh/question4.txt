git reset or git rebase

->git reset --hard HEAD~1
to delete the last N commits-
git reset -- hard HEAD`N

the hard option will delete all the commits permanently and discard and changes in the working branch or file if you want to keep the changes in the file and just delete the comit we can use  --sofr 
-> git reset --soft HEAD~
